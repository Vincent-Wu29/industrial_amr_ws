# M4 预登记实验

2026-10-27，数据采集前固定。

- 场景：narrow_aisle。通道 x=8–12 m、y=12.0–12.8 m，净宽 0.8 m；上方有绕行空间。真实底盘包络保持 0.40 × 0.30 m，Nav2 padding 0.02 m。
- 过程：初始 HOME → (7,12.4) → (7.5,12.4)；正式计时段 (7.5,12.4) → (12.5,12.4)，目标朝向 0。
- Baseline：版本化 nav2.yaml 的 Navfn + DWB，轨迹预测 1.7 s，PathAlign=32、GoalAlign=24。
- Candidate：仅比较 DWB 局部轨迹评价配置，预测 1.2 s，PathAlign=24、GoalAlign=16，其余参数相同。假设较短预测与较小对齐权重可能减少狭窄区域的停顿；该假设须由实际轨迹和数据支持。
- 样本：每组 30 次，种子 42–71，串行运行；每次新建独立世界；两组使用相同的目标实时因子 3，并记录实际达到的比值。Gazebo 与夹具种子固定，AMCL/线程调度仍可能引入变动，因此不宣称逐位可重现。
- 原始产物：manifest、实际参数哈希、系统日志、真值轨迹、每次 metrics.json，包含失败样本；全量样本必须保留。
- 主要指标：成功计时段仿真耗时 P95，目标下降至少 15%；同时成功率不下降，碰撞为 0，真值通道有效。P95 用第 ceil(0.95N) 个排序样本，同时报告 N、均值与中位数。
- 未达到改善门槛、样本不足或成功率降低时，结论为证据不足/候选不成立；不通过缩小 footprint、删除失败或故意恶化基线制造提升。
- 若基线没有复现明显停顿或震荡，报告这一事实，再依据真实问题另行登记实验；不能将参数文件的存在包装为已完成优化。
